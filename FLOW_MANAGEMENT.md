# Управление Flow - Документация

## Обзор

Система управления flow позволяет администраторам настраивать последовательность шагов с аудио для пользователей приложения.

## Структура Flow

Flow состоит из следующих шагов в порядке следования:

1. **Приветствие (welcome)** - Аудио приветствия
2. **Регистрация (registration)** - Пользователь регистрируется (автоматический шаг)
3. **Вступление (intro)** - Аудио вступления после регистрации
4. **Правило 1 (rule1)** - Аудио правило 1
5. **Тезисно правило 1 (thesis1)** - Повторение правила тезисно
6. **Тезисно правило 2 (thesis2)** - Еще раз тезисно правило
7. **Вопрос (question)** - Текст вопроса с 3 кнопками ответов

## Использование админки

### Доступ к управлению Flow

1. Войдите в админку: `/admin/login`
2. Перейдите на страницу управления Flow: `/admin/flow`
3. Или используйте кнопку "Управление Flow" на главной странице админки

### Загрузка аудио

Для каждого шага (кроме registration и question):

1. Нажмите кнопку "Загрузить аудио"
2. Выберите аудио файл (поддерживаются форматы: mp3, wav, ogg и др.)
3. Файл автоматически загрузится в Firebase Storage
4. После загрузки появится кнопка воспроизведения для проверки

### Настройка вопроса

1. На шаге "Вопрос" нажмите "Добавить вопрос"
2. Введите текст вопроса
3. Нажмите "Сохранить"
4. После сохранения появятся 3 ответа:
   - "Понял" (understood)
   - "Понял наполовину" (half-understood)
   - "Не понял" (not-understood)

### Настройка веток

Для каждого ответа на вопрос:

1. Выберите следующий шаг из выпадающего списка
2. Каждый ответ может вести к любому предыдущему шагу
3. Это позволяет создавать разные ветки прохождения flow

## Прохождение Flow пользователем

### Последовательность шагов

1. **Главная страница (`/`)** - Воспроизведение приветственного аудио
2. **Урок (`/lesson?type=intro`)** - Воспроизведение аудио вступления
3. **Урок (`/lesson?type=rule1`)** - Воспроизведение правила 1
4. **Урок (`/lesson?type=thesis1`)** - Воспроизведение тезисно правила 1
5. **Урок (`/lesson?type=thesis2`)** - Воспроизведение тезисно правила 2
6. **Вопрос (`/question`)** - Отображение вопроса с 3 кнопками
7. **Ветка** - Переход к следующему шагу в зависимости от ответа

### Логика переходов

- После каждого аудио пользователь может нажать "Далее" для перехода к следующему шагу
- После ответа на вопрос система автоматически переходит к узлу, указанному в настройках ветки
- Если ветка не настроена, пользователь остается на странице вопроса

## Технические детали

### Типы узлов

```typescript
type FlowNodeType = 
  | 'welcome'        // Приветствие аудио
  | 'registration'   // Регистрация (не аудио, действие)
  | 'intro'          // Аудио вступления
  | 'rule1'          // Аудио правило 1
  | 'thesis1'        // Тезисно правило 1
  | 'thesis2'        // Тезисно правило 2
  | 'question';      // Вопрос с 3 кнопками
```

### Типы ответов

```typescript
type AnswerType = 
  | 'understood'        // Понял
  | 'half-understood'   // Понял наполовину
  | 'not-understood';   // Не понял
```

### Структура данных

Узел flow содержит:
- `id` - Уникальный идентификатор
- `type` - Тип узла
- `title` - Название
- `audioUrl` - URL аудио файла (для аудио-шагов)
- `text` - Текст вопроса (для question)
- `parentId` - ID родительского узла
- `order` - Порядок в последовательности
- `answers` - Массив ответов (только для question)

## API функции

### Для админки

- `getFlowNodes()` - Получить все узлы
- `getFlowNode(nodeId)` - Получить узел по ID
- `saveFlowNode(node)` - Сохранить/обновить узел
- `deleteFlowNode(nodeId)` - Удалить узел
- `uploadFlowAudio(file, nodeId)` - Загрузить аудио

### Для пользователя

- `getStartNode()` - Получить начальный узел (welcome)
- `getNextNode(currentNode)` - Получить следующий узел
- `getNodeAfterAnswer(questionNode, answerType)` - Получить узел после ответа
- `getNodeByType(type)` - Получить узел по типу
- `getAllNodesInOrder()` - Получить все узлы в порядке

## Примеры использования

### Загрузка аудио для правила 1

1. Откройте `/admin/flow`
2. Найдите шаг "Правило 1"
3. Нажмите "Загрузить аудио"
4. Выберите файл
5. Дождитесь загрузки

### Настройка ветки для ответа "Понял"

1. Откройте шаг "Вопрос"
2. Добавьте текст вопроса
3. Для ответа "Понял" выберите следующий шаг (например, "Правило 1" для повторения)
4. Сохраните изменения

## Примечания

- Все аудио файлы хранятся в Firebase Storage
- Порядок шагов определяется полем `order`
- Ветки могут вести к любому предыдущему шагу для повторения материала
- Регистрация - автоматический шаг, не требует настройки
