# 🎵 Быстрая инструкция: Загрузка аудио для приветствия

## 🚀 Самый простой способ (через браузер):

1. **Откройте Firebase Console:**
   - https://console.firebase.google.com/project/quitfreeai/storage

2. **Нажмите "Начать"** (если Storage не включен)

3. **Загрузите файл:**
   - Нажмите **"Загрузить файл"**
   - Выберите ваш аудио файл (например, `welcome.mp3`)
   - Создайте папку `audio` или загрузите прямо в корень

4. **Скопируйте URL:**
   - Кликните на загруженный файл
   - Скопируйте **Download URL**
   - Используйте его в компоненте `<AudioPlayer>`

---

## 📝 Пример использования:

```tsx
// В вашем компоненте приветствия
<AudioPlayer 
  src="https://firebasestorage.googleapis.com/v0/b/quitfreeai.appspot.com/o/audio%2Fwelcome.mp3?alt=media&token=..."
  title="Добро пожаловать в QuitFree.ai"
/>
```

---

## 📁 Рекомендуемая структура:

```
Firebase Storage:
  └── audio/
      ├── welcome.mp3      ← Загрузите сюда приветствие
      ├── intro.mp3
      └── lesson-*.mp3
```

---

## 💡 Советы:

- ✅ Используйте формат **MP3** (лучшая совместимость)
- ✅ Оптимизируйте размер (128-192 kbps достаточно)
- ✅ Название файла: `welcome.mp3` или `welcome-audio.mp3`
- ✅ Максимальный размер: до 10 МБ (для быстрой загрузки)
